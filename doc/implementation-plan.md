# AIAA 3111 NHANES 项目实现计划

本项目使用 NHANES 2017–2018 周期数据，研究 20 岁及以上参与者的五项代谢相关异常如何共现、哪些组合与较差的自评健康相关，以及结果对筛选参数和样本变化是否敏感。Codex 负责实现 Python 工作流、运行分析、生成表图和制作提交材料。各阶段按依赖顺序推进，每阶段通过验收后进入下一阶段。[课程提案](../NHANES_Proposal.pdf)

| 阶段 | 里程碑 | 完成条件 |
|---|---|---|
| 1 | 下载和清洗 | 七个 XPT 文件可自动获取，变量字典和样本流失表已生成，分析默认参数已写入配置 |
| 2 | 模式挖掘和性能比较 | 两种算法与直接计数结果一致，规则表和计时表可复现，验证候选已锁定 |
| 3 | 健康验证和稳健性检查 | 留出验证、加权摘要和主要稳健性检查已运行，四类核心图已生成并核对 |
| 4 | 海报和展示准备 | `Poster.pdf`、配套讲稿和答辩要点已准备 |
| 5 | 报告和最终打包 | 完成 6–10 页报告、干净环境复跑和最终 ZIP 验收 |

## 1. Python 工作流与产物

使用 Python 3.11 或更高版本，在 `venv` 或 Conda 创建的独立环境中安装、运行和复现项目。以 `pandas` 读取 XPT 和处理表格，使用 NumPy、SciPy、statsmodels 和 Matplotlib 完成计算、回归和绘图。依赖版本和分析参数随项目保存。

使用 `venv` 时，在项目根目录运行以下命令。

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

也可以创建并激活 Conda 环境。

```bash
conda create -n nhanes-project python=3.11 pip
conda activate nhanes-project
```

激活所选环境后，使用以下命令安装并运行实现完成的工作流。

```bash
python -m pip install -e .
python -m nhanes_project run --config config/analysis.toml
```

| 路径 | 用途 |
|---|---|
| `pyproject.toml`、`config/analysis.toml` | 安装、依赖版本和运行参数。集中保存数据周期、阈值、随机种子和输出路径 |
| `src/nhanes_project/` | 下载与清洗、项集与规则、性能评估、健康与抽样分析、稳健性检查、绘图和命令行入口 |
| `data/raw/` | CDC XPT 本地缓存。记录数据来源和 SHA-256，成功读取后才接受下载文件 |
| `outputs/tables/`、`outputs/figures/` | 从同一次运行生成报告和海报所需的统计表及图件 |
| `outputs/run_manifest.json` | 记录输入文件哈希、配置、软件版本、各阶段人数和运行状态 |
| `doc/`、`README.md` | 实现计划、数据字典、报告与海报素材，以及数据获取和复跑说明 |

### Git 管理与提交

使用 Git 跟踪提案、代码、配置、依赖声明和文档。通过 `.gitignore` 排除本地环境、Python 缓存、下载的数据和可重新生成的运行产物。先提交项目基线，再在数据处理、算法比较、健康验证及稳健性检查、海报与报告等形成可独立核对的成果时分别提交。每次提交前运行相关检查、查看待提交差异，并用提交说明概括改动。最终交付前从待交付版本复跑并核对 ZIP。

## 2. 数据处理与分析样本

1. 从 CDC 获取 `DEMO_J`、`BMX_J`、`BPX_J`、`GHB_J`、`HDL_J`、`TCHOL_J` 和 `HSQ_J`。检查每个表的 `SEQN` 唯一、非空且所需字段齐全。以 `DEMO_J` 为主表进行一对一左连接，核查连接前后总行数一致，记录各组件无法匹配的人数。[CDC 2017–2018 数据与文档](https://wwwn.cdc.gov/nchs/nhanes/search/DataPage.aspx?Cycle=2017-2018)
2. 以 `RIDAGEYR ≥ 20` 且参加移动体检中心体检为分析资格。保留年龄、`RIAGENDR`、`WTMEC2YR`、`SDMVSTRA` 和 `SDMVPSU`。输出合并后、成年体检、五项指标完整、自评健康有效及发现集和验证集的人数。按指标统计缺失，并比较五项完整者与不完整者的年龄和性别。[CDC `DEMO_J` 变量字典](https://wwwn.cdc.gov/nchs/data/nhanes/public/2017/datafiles/DEMO_J.htm)
3. 用下表生成可空布尔变量。得到五项测量均完整的主分析样本后，每人对应一行事务，五项均正常者保留在支持度分母中。以 `SEQN` 排序后，用固定种子 `3111` 按参与者做 70% 发现集和 30% 验证集划分，并检查两组 `SEQN` 无交集。抽样方差计算另保留全部有正体检权重的记录，由分析域指示变量标记成年、完整案例等条件。

| 异常项 | 变量 | 主分析界值 |
|---|---|---|
| 中心性肥胖 | `BMXWAIST` | 男性 >102 cm，女性 >88 cm |
| 血压升高 | `BPXSY1–4`、`BPXDI1–4` | 对有效成对读数分别求均值。收缩压 ≥130 或舒张压 ≥85 mmHg。无有效成对读数时记为缺失，保留变量字典允许的舒张压零值 |
| HbA1c 升高 | `LBXGH` | ≥5.7% |
| HDL 偏低 | `LBDHDD` | 男性 <40 mg/dL，女性 <50 mg/dL |
| 总胆固醇偏高 | `LBXTC` | ≥240 mg/dL |

这些界值用于定义独立的二元异常项。腰围、血压、HDL 和总胆固醇界值来自 ATP III，HbA1c 界值来自 CDC。[NHLBI ATP III 完整报告](https://www.nhlbi.nih.gov/files/docs/resources/heart/atp-3-cholesterol-full-report.pdf) · [CDC HbA1c 界值](https://www.cdc.gov/diabetes/diabetes-testing/) · [CDC 血压变量字典](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/BPX_J.htm)

## 3. Apriori、FP-Growth 与规则筛选

1. 分别实现 Apriori 的逐层候选生成与剪枝，以及 FP-Growth 的 FP-tree 和条件模式递归。统一输入事务、最大项集长度 3 和最小支持人数，后者取 `ceil(支持度阈值 × 事务数)`。为五个异常项直接枚举一至三项组合，核对两个算法输出的项集和原始计数。在已知的小型事务上验证空事务、阈值边界和三项组合，再对实际数据逐个阈值做一致性核查。[Apriori 原论文记录](https://www.sigmod.org/publications/dblp/db/conf/vldb/vldb94-487.html) · [FP-Growth 原论文记录](https://sigmod.org/publications/discs/2001/out/p_miningfrequentpjijiy.htm)
2. 由同一函数从频繁项集生成规则。输出前件、后件、两者各自人数、共现人数、总人数、支持度、置信度、提升度和杠杆率。主设定为支持度 ≥5%、置信度 ≥50%，补充支持度 2%、5%、10% 与置信度 30%、50%、70% 的参数网格。
3. 在发现集上筛选至少有一条满足主设定且杠杆率为正的规则的二项或三项组合，要求组合共现人数 ≥30。按合格规则中的最高杠杆率降序、共现人数降序、项集名称升序排序，保留最多 5 组，保存至 `candidate_itemsets.csv`。筛选阶段只读取发现集的异常项，验证阶段读取已锁定的候选文件。符合条件的组合较少时，按实际数量报告。
4. 性能测试在同一环境中对配对的 25%、50%、100% 发现集样本运行两种算法，使用同一参数和输入，每个设置预热后重复 10 次。计时覆盖挖掘本身，记录中位数、四分位距、样本量、环境和频繁项集数量。结论限于本项目的实现和五项异常的输入规模。

## 4. 留出验证与加权摘要

1. 按 CDC 字典，将 `HSD010=4–5` 视为自评健康一般或较差，`1–3` 视为良好及以上，`7`、`9` 和空值计作缺失。在验证集中报告有效问卷分母。对每个锁定项集，比较具备该组合全部异常项者与其余参与者，输出两组总人数、结局人数、结局比例和比例差（百分点）。[CDC `HSD010` 变量字典](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/HSQ_J.htm)
2. 对信息量足够的组合，用逻辑回归估计年龄和性别调整后的 OR 与 95% 置信区间。模型按组合单独拟合，以 `SDMVSTRA` 和 `SDMVPSU` 的组合作为聚类标识，输出探索性的聚类稳健区间。组合存在组或对照组若少于 10 个结局事件或少于 10 个非事件，或出现分离、收敛失败，保留描述性结果并标出模型状态。若报告显著性检验，同时给出跨候选的 Holm 校正结果。
3. 另用全周期成年体检样本报告锁定组合的加权频率，以及各组自评健康一般或较差的加权比例。以 `WTMEC2YR` 计算点估计，使用 `SDMVSTRA` 和 `SDMVPSU` 对分析域做 Taylor 线性化并生成区间。用 CDC 的 R `survey` 示例方法独立核对至少一个主结果的估计值与标准误，标出不稳定的小样本估计。留出验证表和全样本加权表分别标明样本及分母。报告解释完整案例选择对总体外推的限制。[CDC 权重指南](https://wwwn.cdc.gov/nchs/nhanes/tutorials/weighting.aspx) · [CDC 方差估计指南](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx) · [CDC 估计值可靠性指南](https://wwwn.cdc.gov/nchs/nhanes/tutorials/reliabilityofestimates.aspx)

## 5. 稳健性、图表和交付验收

- **稳健性。** 汇总各参数组合的项集数、规则数和主要项集排序。对发现集重复 100 次无放回抽取 80% 的参与者，报告候选组合的重新入选比例和提升度变化。按年龄组（20–39、40–59、60 岁及以上）及性别分别报告主要组合的共现率和样本量。用每个候选组合相关指标齐全的更宽样本重新计算共现率，并与五项全部齐全样本的同口径结果比较，检查完整案例筛选的影响。
- **核心图表。** 生成两两共现热图、代表性规则网络、支持度与提升度比较图、自评健康分布图。规则网络保留完整的规则前件和后件，图注列明分母、分析集和权重口径。验证结果较弱、稀疏或不稳定时，直接呈现其估计和样本量。
- **海报与报告。** `Poster.pdf` 包含研究问题、样本筛选、算法比较、代表性模式、留出验证和局限。6–10 页报告补齐方法、参数、稳健性、抽样设计和复现说明。解释范围限于同一调查周期的横断面统计关联。报告引用数据和外部方法，按提案披露 AIGC 使用情况。
- **复现验收。** 从空数据缓存和新环境按 `README.md` 运行。核查七张表的一对一合并、缺失未转为正常、空事务分母、血压和问卷编码边界、项集精确计数、集合划分、候选锁定和加权分母。复跑时样本数、项集、规则和统计表应一致，计时允许波动。逐项比对报告、海报和导出表中的数字，核对 PDF 图表可读性，并在干净目录解压最终 ZIP 验证文件完整。
